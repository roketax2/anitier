# AniTier

Свой топ аниме: оценки по 10-балльной шкале, рейтинг и тир-лист, поиск и фильтры.
Работает в браузере и ставится на телефон как приложение.

Сайт: https://roketax2.github.io/anitier/

- Данные об аниме — открытый API [Shikimori](https://shikimori.io).
- Оценки хранятся в браузере, а после входа в аккаунт — ещё и на сервере: топ одинаковый на всех устройствах, можно открыть ссылку на свой топ.
- Аккаунты: логин и пароль (код восстановления), почта (код из письма), Google. Сервер — папка worker/ (Cloudflare Worker + D1, anitier.stalzoneai.com).
- Без сборки: обычные HTML, CSS и JS. Локально: `node tools/serve.js` → http://localhost:5190
